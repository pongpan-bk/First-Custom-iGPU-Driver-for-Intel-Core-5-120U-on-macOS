## งานต่อ (ถัดไป)

1. **ทดสอบ selector 12-14** ด้วย harness (`myintelvcs_bridge.c`):
   - `ExecBatch` → ใส่ command stream ลง GEM buffer แล้ว submit
   - `WaitBatch` → poll seqno ที่ HWSP offset 0x80
2. **ปิด bug batch 4 dwords**: `HEAD=0xC, ESR=0x1` — probe batch มี 4 dwords
   (BB_START → bbGgtt → 0x05000000 → 0x00000000) fault ที่ dword 4
   → คาดว่า PPGTT mapping ของ bbGgtt หรือ batch ไม่มี BB_END
3. **hardware test จริง** (ผู้ใช้ต้อง authorize) — deploy ไป EFI/OC/Kexts
   แล้วรัน harness decode H.264 bitstream จริง
